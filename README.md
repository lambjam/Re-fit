# Re-fit 🌿

**Re-fit** is a circular community platform dedicated to giving pre-loved clothes a second life. We divert wearable garments from landfills, sanitize and re-fit them, and connect them with local shelters and families in need.

---

## 🐶 Homepage Landing Screen Experience

The landing screen features a custom animated intro based on the Re-fit brand concept:

1. **Starry Twilight Sky & Grassy Field**: A serene navy-blue evening sky filled with twinkling small white stars and gentle rolling green hills.
2. **The Falling Hanger**: A wooden/metallic clothes hanger drifts gracefully down through the evening breeze.
3. **Clothes Pile Impact**: The hanger plunges into a cozy pile of folded garments (matching the exact palette of cozy cream cable knits, mauve trousers, vintage Breton stripes, and olive sweaters beside a cardboard `DONATE` box).
4. **Doggo Mascot ("Sprout") Pops Out**: Out springs Sprout—the mocha-taupe puppy mascot with pink-interior ears, anime-shine eyes, folded green tee in paws, and an organic leaf sprout on its head!
5. **Brand Reveal ("Meet re-fit")**: The signature logo emerges featuring organic sprout leaves on the `r` and a dangling hanger under the hyphen `-`.
6. **Interactive Mascot**: Clicking on Sprout triggers joyful tail wags, playful barks, and eco-friendly tips.

## 🚀 Running the Project

You can run the site in any of the following ways:

### Option 1: Built-in Node Server (Zero External Dependencies)
```bash
node server.js
# Opens at http://localhost:3000
```
or with npm:
```bash
npm start
```

### Option 2: Open Directly in Browser
Double-click [`index.html`](file:///c:/Users/prmth/OneDrive/Documents/Refit/index.html) to open it directly in Chrome, Edge, Safari, or Firefox.
